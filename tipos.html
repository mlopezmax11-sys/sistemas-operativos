Tipos de sistemas operativos

Hay muchas formas de clasificar un sistema operativo, ya sea según sus usuarios, tareas o recursos, así como por el entorno y su propósito. Estas tipologías se solapan y se complementan entre sí.

Según Usuarios y Tareas

Monousuario / Multiusuario

Un sistema puede limitarse a un único usuario o permitir que varias personas trabajen simultáneamente con total aislamiento y gestión de permisos.

Monotarea / Multitarea

Los sistemas operativos antiguos eran monotarea; hoy en día lo habitual es la multitarea con planificación, explotando el multinúcleo y multiprocesamiento.

Monosesión / Multisesión

Sistemas clásicos solo permitían una sesión activa (Windows 95/98), frente a los entornos multisesión típicos de servidores como Windows Server o Linux.

Centralizado / Distribuido

Un SO puede gestionar los recursos de una sola máquina física, o bien orquestar varias computadoras para ofrecer un sistema lógico unificado.

Por Entorno y Propósito

Sistemas de Escritorio

Windows, macOS y Linux de escritorio. Priorizan por completo la usabilidad, compatibilidad y productividad en ordenadores personales.

Sistemas Móviles

Android e iOS optimizan la interacción táctil y la eficiencia energética. También existen variantes como webOS o watchOS en segmentos específicos.

Servidores

Windows Server, Unix y distribuciones Linux (Debian, Ubuntu Server, RHEL). Están orientados a la fiabilidad, seguridad y gestión de cargas concurrentes.

Sistemas Embebidos

FreeRTOS, VxWorks, QNX o Linux embebido. Se instalan en dispositivos con recursos muy limitados como IoT, automoción, routers y maquinaria.

Mainframe

Plataformas como IBM z/OS, diseñadas exclusivamente para procesar transacciones masivas con disponibilidad extrema en banca, seguros o aerolíneas.

Virtualizados / Hipervisores

Tipo 1 (VMware ESXi, Hyper‑V) y Tipo 2 (VirtualBox, VMware Workstation). Permiten ejecutar múltiples máquinas virtuales sobre un mismo hardware.

Cloud OS (Sistemas en la Nube): Entornos basados en virtualización y contenedores (como OpenStack o Kubernetes) para gestionar recursos de cómputo a gran escala en centros de datos y nubes públicas.

Por Modelo de Ejecución

Por Lotes (Batch)

Un operador agrupa trabajos similares en lotes y el sistema los procesa de forma automática sin interacción directa. Se emplea en tareas periódicas de gran volumen como nóminas o estados bancarios (Ej. SCOPE o EXECII).

Tiempo Compartido

El sistema alterna entre tareas otorgando pequeños intervalos de tiempo a cada una, dando servicio a múltiples usuarios a la vez de forma interactiva. UNIX popularizó este modelo, que es la base de los sistemas actuales.

Tiempo Real (RTOS)

Priorizan de forma estricta tiempos de respuesta garantizados ante estímulos externos. Son utilizados en robots, control de tráfico aéreo o sistemas industriales, dividiéndose en tiempo real estricto y flexible.

Sistemas Distribuidos

Varios equipos independientes con su propia CPU colaboran entre sí a través de una red para ofrecer mayor potencia de computación y un acceso remoto totalmente transparente (Ej. Sprite, Taos, Solaris-MC, Mach, Amoeba).

Sistemas de Red

Están diseñados específicamente para ejecutarse y administrarse en servidores centrales que coordinan usuarios, grupos, permisos y servicios compartidos como archivos o autenticación (Ej. Clásicos como Unix y NetWare).
