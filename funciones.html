Principales funciones

El sistema operativo actúa como el intermediario crucial entre el usuario, las aplicaciones y el hardware. Para lograr esto, realiza una serie de funciones esenciales:

Gestión de procesos

Controla la ejecución de los programas en segundo plano y primer plano, asignando eficientemente el tiempo de procesamiento de la CPU.

Gestión de memoria

Administra el espacio de la memoria RAM, asignando recursos cuando un programa lo necesita y evitando conflictos o cierres entre aplicaciones.

Sistema de archivos

Organiza, estructura y controla el almacenamiento de todos los datos, carpetas y archivos en el disco duro o unidades de almacenamiento.

Gestión de dispositivos

Permite la comunicación directa con el hardware periférico a través de los controladores (drivers), como teclados, mouse, monitores o impresoras.

Interfaz de usuario

Facilita la interacción humana con la máquina mediante entornos visuales gráficos (GUI) o consolas de comandos de texto (CLI).

Seguridad

Protege la información general del sistema mediante la gestión de cuentas de usuarios, contraseñas seguras y permisos de archivos.

Optimización de prioridades en procesos

La máquina establece prioridades arbitrarias a las tareas a realizar y, a veces, las menos importantes se quedan sin ejecutar. Para resolver esto, el sistema permite modificar la configuración de la herramienta de gestión de procesos para otorgar una mayor prioridad a las tareas necesarias o forzar su ejecución de forma manual cuando sea requerido, actuando de manera similar a cómo un oficinista reorganiza su línea de acción.

Gestión del almacenamiento secundario

Debido a que la memoria principal pierde su contenido ante cualquier fallo eléctrico, el sistema coordina un segundo módulo para resguardar los datos a largo plazo. Se encarga por completo de administrar el espacio libre disponible, asignar el orden de guardado y asegurar que toda la información quede perfectamente registrada en las unidades de disco.

Comunicación entre elementos y aplicaciones

Mantiene un enlace constante entre los distintos componentes de hardware de la máquina y todos los programas de software que interactúan con ellos. A través de las interfaces físicas o lógicas del sistema, administra el envío y la recepción de paquetes de datos para asegurar una interacción interna fluida.

Informar del estado del sistema

Ofrece un entorno operativo básico y emite alertas en tiempo real sobre la situación de la máquina, notificando si se requiere una acción del usuario o la aprobación de actualizaciones automáticas. Asimismo, integra herramientas nativas de soporte para que múltiples lenguajes de programación e instrucciones sean operativos.

Gestión global de recursos

Ejerce el rol de administrador general sobre todos los recursos internos y externos que entran en contacto con el sistema informático. Supervisa la carga de la unidad central de procesamiento (CPU) y, cuando es necesario, realiza tareas de limpieza interna moviendo fragmentos de datos guardados entre la memoria interna y la memoria secundaria.

Administración de usuarios y perfiles

Regula los perfiles individuales creados dentro del dispositivo. Puede operar en modalidad monousuario, garantizando que únicamente permanezcan activas las ejecuciones de una sola cuenta a la vez, o en modalidad multiusuario, la cual faculta al sistema para procesar las tareas de múltiples personas al mismo tiempo de forma independiente.
